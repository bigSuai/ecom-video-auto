# B 商品资料整理与检查

所需字段：products中的name、sku、spec、price、stock；可带platform/shop_id/currency与来源。使用 [输入约定](inputs.md) 映射后运行B。

先展示changes表的before/after，说明哪些格式被统一，再展示issues：缺项、非法价、非法库存、重复编码、同编码冲突价。名称/规格只修首尾空白，编码保留大小写、全半角和前导零；价格与库存只转换明确的全角数字、千分位，人民币符号只用于人民币或未指定币种，不能把美元符号当人民币删掉。

标准price为正、最多两位有效小数且不超过999999999999.99；stock为0至999999999999整数。非法值仍展示已执行的明确格式转换，不补猜缺项。重复判断按平台/店铺/sku，所有行保留。

检查合格只代表规则合格，不证明真实可售库存或平台资质。数字型Excel编码、重复或冲突需有据确认，不能自动选一行覆盖。导出normalized/changes/issues；向用户报告实际处理数、问题类别和run.json用时。原表不覆盖。

上游成员检查器是可选来源，本包独立可运行。后续上架参考A，将已确认name映射title并补平台特有必填项。
